# Published skills

Add each reusable skill as its own folder under this directory.

Expected structure:

```text
skills/
  my-skill/
    SKILL.md
    helper-script.ps1
    examples.md
```

## Available now

- `check-wcag` - Accessibility review skill for WCAG 2.1 AA audits in KEX-style Svelte/Sitevision apps.
