# Skill template

Replace this file with task-specific instructions for Copilot.

## Recommended structure

1. Start with when the skill should be used.
2. Describe the exact workflow Copilot should follow.
3. Reference any local scripts or helper files in this directory.
4. Include constraints, guardrails, and expected output.

## Example

When the user asks for this skill, follow these steps:

1. Inspect the relevant files before making changes.
2. Use the scripts or reference files bundled with this skill if needed.
3. Make the requested change.
4. Summarize the outcome clearly.
